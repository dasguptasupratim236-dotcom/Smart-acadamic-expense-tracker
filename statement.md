# problem statement and scope

## problem statement
college student frequently struggle to monitor variable daily expenditures,leading to budget deficits and poor monthly allowance management

## scope of the project
the smart acadamic expense tracker provides an objective-oriented python application allowing students to get spending limits,categorize transactions ,generate numerical spending reports,and save state locally using json stroage.

## target users
higher education students and academic researchers.

## high level features
- transaction tracking(CRUD operations)
- budget threshold perccentage calculations
- input validation and exception handling 
- modular file arcchitecture and presistent json storage
